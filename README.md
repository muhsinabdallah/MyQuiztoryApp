# Quiztory App

Quiztory is an interactive quiz application for Android that tests users' knowledge of ancient Egyptian history. 
It includes 10 multiple-choice questions, feedback for each answer, a scoring system, and high-score tracking.

## Features

- Multiple-choice questions with immediate feedback
- Tracks correct and incorrect answers
- High score is saved and updated
- Progress bar and navigation between questions
- Result screen with detailed performance feedback
- Clean UI following Material Design guidelines

## Technologies Used

- Java
- Android Studio
- XML
- MVC Architecture
- SharedPreferences (for storing high score)
- Unit Testing with JUnit
